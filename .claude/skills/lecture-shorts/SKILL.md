# 수업 하이라이트 쇼츠

줌 수업 녹화본에서 구간을 골라 홍보용 세로 쇼츠(1080×1920)를 만든다. 지금까지 만든 것: 9/10, 9/13(EP.01~05), 9/19 시안, 10/10·10/11 주말 특강 시안 A·B·C, 10/16 중2 기하 필기 설명 5편. 새 편은 **가장 비슷한 이전 편을 복사해서** 시각·좌표만 새로 잰다.

**역할:** 디자인·문구·고를 구간은 사용자가 정한다. 아래 "정해진 것"은 사용자가 확정한 값이니 임의로 바꾸지 않는다. 새 디자인 요소가 필요하면 시안 2~3개를 만들어 고르게 한다.

## 0. 먼저 물을 것

1. **어느 수업인지** — 날짜·시간대. 녹화본 이름이 `~/classvideo/archive/YYYY-MM-DD HH-MM-SS.mp4` 라 날짜로 찾는다.
2. **어디에 쓰는지·어떤 형식인지** — 형식마다 길이·배치 기준이 다르다.

| 형식 | 예 | 길이 | 배치 | 복사해 올 편 |
|---|---|---|---|---|
| 수업 하이라이트(홍보) | 주말 특강 시안 A·B, 9/13 EP | **1분 이내** | 위 캠 852×480 + 아래 판서 | `clips-1010-1011.ts` DATA_1010B60 (시안B 1분) |
| 학생이 직접 설명 | 시안 C1~C3, 9/19 시안 | 1분 이내, **10초 안에 학생 등장** | 위와 같음 + `kid` 배지 | `clips-1010-1011.ts` DATA_1011A1 (시안 C1) |
| 필기 설명(개념) | 외심·내심·비교표·평행사변형·사각형 | 1분 넘어도 됨 | `noteBoard`(캠 568×320 / 판서 1320) + `boardKeys` | `clips-1016.ts` DATA_1016I |
| 얼굴 없는 필기 설명 | 외심_필기만 | 같음 | `noFace` + `bubble: "glass"` | `clips-1016.ts` DATA_1016O (10/22 부터 얼굴 없는 판) |

사용자 방향: 게임·넌센스 퀴즈 말고 **수업 자체** — 어떤 문제를, 어떻게 풀고 설명하고, 아이들이 어떻게 참여하는지.

## 1. 원본 찾기

| 무엇 | 위치 |
|---|---|
| 녹화본(화면 + 오른쪽 위 선생님 캠, 1080p30) | `~/classvideo/archive/YYYY-MM-DD HH-MM-SS.mp4` |
| 얼굴캠 원본(무음, 1920×1080) | `~/classvideo/work/facecam/얼굴캠 <같은 이름>.mov` (압축된 수업은 `.mp4`) |
| 채팅 | `~/classvideo/chat/익명/`, `~/classvideo/chat/원본/` (파일명 = 수업 시작 날짜·시각) |
| 작업 파일(받아쓰기 등) | `source/MMDD/` (git 제외) |
| 잘라 낸 클립 | `public/clips/MMDD<편>/` (git 제외) |

- 얼굴캠은 압축 작업(`~/classvideo/logs/facecam_compress.log`)이 원본을 지우고 옮기기도 한다. 폴더가 없으면 `find ~ -iname "*얼굴캠*"` 으로 찾아보고, 없으면 사용자에게 묻는다. 끝내 없으면 녹화본의 캠 자리를 잘라 보정해서 쓴다(9/13 방식: 원본 426×240 이라 **2배 이상 확대 금지**, `hqdn3d,scale=…:flags=lanczos,unsharp,cas`. AI 업스케일은 사용자가 거절함).
- 녹화본 앞뒤·쉬는 시간 전후의 **갤러리 뷰에는 아이들 얼굴이 나온다** → 쓰지 않는다.

## 2. 받아쓰기와 읽기본

맥미니 GPU(mlx-whisper)로 수업 하나에 7~8분. CPU faster-whisper 는 40분 넘게 걸리니 쓰지 않는다.

```bash
D=source/MMDD; V="$HOME/classvideo/archive/YYYY-MM-DD HH-MM-SS.mp4"; mkdir -p $D
ffmpeg -v error -i "$V" -vn -ac 1 -ar 16000 $D/a.wav
~/.venvs/whisper/bin/python source/transcribe_mlx.py $D/a.wav $D/transcript_a.json   # → transcript_a.json·txt
python3 source/group_min.py $D/transcript_a.json $D/min_a.txt                         # 1분 단위 읽기본
python3 source/chat_flat.py "<채팅 파일>" HH:MM:SS $D/chat_a.txt                       # 채팅을 영상 시각으로(HH:MM:SS = 영상 0초 시각, 파일명 시각에서 시작)
```

- 오래 걸리니 `run_in_background` 로 돌린다. 수업이 여러 개면 a, b, c 로 이어서.
- 받아쓰기는 틀린다(수 읽기, 학생 말). 후보를 고른 뒤 그 구간만 단어 단위로 다시 받아쓴다(4단계).

## 3. 후보 구간 제안 → 사용자가 고름

`min_*.txt` 와 채팅을 읽고 후보를 **표로** 제안한다(분 구간 / 무슨 장면 / 왜 홍보가 되는지 / 학생 발화·이름 여부). 메모리 `lecture-highlight-*.md` 에 이전 후보 목록 형식이 있다.

좋은 후보:
- 아이가 **직접 풀이를 설명**하는 곳, 친구 설명의 틀린 곳을 다른 친구가 짚는 곳(★ 사용자가 가장 원함)
- 고정관념을 깨는 반전("다 더했는데 101%?"), "통분하면 멈추세요" 같은 한마디 훅
- 아이들이 선생님 실수를 짚거나, 채팅 반응이 몰리는 곳
- 습관·태도 메시지("틀려도 괜찮아", "답보다 다 세봤는지가 중요")

고른 뒤 편 제목·훅을 제안한다. 처음 보는 사람이 뜻을 모르는 제목("붕어빵의 함정")은 안 누른다 → 썸네일 메인은 **학부모가 바로 알아듣는 메시지**("초등 수학은 ~해야 합니다"), 편 제목은 작은 태그로. 아이·친구가 나오는 장면은 긍정적인 틀로 잡는다("친구가 틀린 걸 고친다" ×).

## 4. 구간 다듬기 — 단어 시각 + 개인정보

```bash
~/.venvs/whisper/bin/python source/words_mlx.py $D/a.wav 시작초 끝초 $D/words_<편>.txt   # 원본 기준 단어@시각
python3 source/f0.py $D/a.wav 시작초 끝초                                                  # 목소리 높이: 선생님(낮음)/학생(높음) 구분
```

- **학생 이름·지역·학년이 나오는 곳은 구간 사이로 빠지게 자른다**(호명 "○○가 한번 설명해 볼까?"도). 실명은 받아쓰기·채팅 어디에서든 쇼츠·자막·일지·커밋 메시지에 쓰지 않는다. 학생 표기는 "친구"/"첫 번째 친구"(학년 매칭이 확실할 때만 "초4 친구").
- 학생 말하는 구간은 `kid` 로 표시 → 음높이를 1.15배(살짝)로 올린다.
- 채팅에도 실명·지역이 섞여 있다. 화면에 보일 채팅은 하나씩 확인한다.
- 같은 말 반복·긴 공백은 구간을 나눠 뺀다. 학생 대답을 기다리는 침묵도 줄인다.
- 필기 설명형은 **필기가 화면에 써지는 장면**을 쓰는 게 원칙(빈 칸을 보며 말하는 구간 대신 쓰면서 말하는 구간).

## 5. 컷 — `source/cut_MMDD.py`

가장 최근 컷 스크립트 `source/cut_1016.py` 를 복사해 `EPS` 만 새로 쓴다. 이미 들어 있는 처리:
- `parts` 구간들을 이어 붙임(경계 0.03초 페이드), `kid` 구간만 피치 1.15(맥미니 ffmpeg 에 rubberband 없어 asetrate+atempo)
- 녹화본의 캠 자리(`CAMBOX`)를 바로 아래 배경색으로 덮음 — 판서 위로 캠이 겹쳐 보이지 않게. 오른쪽 흰 여백(x≥1575)은 빼고 색을 잼
- 얼굴캠에서 같은 구간을 잘라 `cam_<클립>.mp4`(852×480) 로 저장, `face_off` 로 싱크

**얼굴캠 시간차(face_off)** — 수업마다 다르다(지금까지 −0.033 ~ −0.533). 선생님이 움직이는 시각 2~3곳에서 재서 같은 값인지 본다:

```bash
python3 .claude/skills/lecture-shorts/scripts/facecam_sync.py "$V" "<얼굴캠 파일>" 시각초 [--cam x,y,w,h]
```

**캠 자리**는 수업마다 조금 다르다(보통 1448,0,472,268 / 10/13 저녁은 1454,0,466,262). 한 프레임 뽑아 확인한다: `ffmpeg -ss T -i "$V" -frames:v 1 check.png`.

```bash
python3 source/cut_MMDD.py A            # 편 A 전체
python3 source/cut_MMDD.py A a3         # 클립 하나만 다시
```

출력의 `dur=` 를 클립 데이터 `duration` 에 그대로 쓴다. 자른 클립은 다시 받아써서 이름이 남지 않았는지 확인한다: `~/.venvs/whisper/bin/python source/clip_words.py public/clips/MMDDa/*.mp4`(이 단어 시각이 자막 시각이 된다).

## 6. 클립 데이터·컴포지션

- `src/LectureHighlight/clips-MMDD.ts` — 형식은 `clips.ts` 맨 아래 타입 주석이 설명서. 비슷한 이전 편을 복사.
  - `board`: 판서 영역(원본 좌표). 넓으면 `fit: "contain"`. 필기형은 `boardKeys`(시각별 확대·이동, 프레임 차이로 새 필기 범위를 계산해 정함)
  - `captions`: 클립 안 시각. 만드는 법은 **captions 스킬**(`.ts` 형식 출력). 학생 말은 `who: "kid"` — 변조돼 잘 안 들리니 **학생 말은 전부 자막**
  - `kid` / `kidLabel`, `chats`(이모지 반응·채팅 강조), `label`(챕터 제목, 빈 문자열이면 앞 챕터에 이어짐)
  - 챕터 제목은 문제 내용보다 "이 수업이 어떤 수업인지"(손 들고 답해요 / 틀린 이유까지 콕 …)
- `src/Root.tsx` 에 `LectureHighlightMMDD<편>Shorts`(HighlightShorts, `shortsDuration(DATA)`) 와 썸네일 컴포지션을 등록. 필기형 썸네일은 `NoteThumbnail` + `data.cover`, 나머지는 `HighlightThumbnail`.
- 타입 확인: `npx tsc --noEmit`

## 7. 렌더 → 확인 → 보고

```bash
npx remotion render LectureHighlightMMDDaShorts "out/<폴더>/<이름>.mp4"
npx remotion still ThumbnailMMDDa "out/<폴더>/<이름>_썸네일.png"
```

- 출력 폴더·파일명은 편 종류별로 모은다: `out/경시특강_shorts/EP0N_제목.mp4`, `out/주말특강_시안/시안A_제목.mp4`, `out/필기설명/주제_개념설명.mp4` 처럼 `<이름>.mp4` + `<이름>_썸네일.png`.
- 렌더 전 Studio 미리보기가 필요하면 `npm run dev`(포트 3000, VS Code가 PC로 전달).
- 확인: 자막이 바뀌는 시각 몇 곳에서 프레임을 뽑아 본다(`ffmpeg -ss T -i out.mp4 -frames:v 1 x.png`). 캠 자리 덮개가 밝은 상자로 보이지 않는지, 캠과 입 모양 싱크, 이름 컷 이음새, 첫 프레임이 완성된 타이틀 카드인지(쇼츠는 첫 프레임이 자동 썸네일). 확인용 이미지는 scratchpad 에 두고 사용자에게 내밀지 않는다.
- 사용자에게는 결과물 경로, 길이, 다듬은 자막·뺀 구간(이름 컷 등)만 알린다. 소리 이음새는 정지 화면으로 확인이 안 되니 "처음부터 끝까지 재생 확인은 아직"이라고 분명히 말한다.

## 정해진 것 (사용자 확정)

- 썸네일 얼굴: 표정 밝고 정면인 순간을 **얼굴캠 원본 전체**에서 고른다(클립 구간에 한정하지 않음). 사용자가 "표정 별로"라고 하면 웃음·OK 손짓 장면으로.
- 썸네일 문구 틀(필기형): "중2 도형의 첫 단추 / [[주제]] / 필기 한 장으로 정리". 필기형 본편 첫 3초도 같은 카드(`data.cover`).
- 쇼츠 첫 프레임은 페이드 없이 완성된 타이틀 카드. 학생 음성 피치 1.15. 자막은 `[[단어]]` 강조.
- 아웃트로: "카이스트 박사 선생님과 함께하는 / 초등 수학 경시 특강 / 대치동캐슬에서 만나요" + 텍스트 링크 + "링크는 댓글에 👇" + `litt.ly/klee_castle`. QR 없음. 별명은 "카박준쌤".
- 원본·받아쓰기·채팅(`source/`, `public/`)은 실명이 있어 커밋하지 않는다. 컷 스크립트(`source/*.py`)와 `src/` 만 커밋.
