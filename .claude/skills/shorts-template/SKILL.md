# 쇼츠 템플릿 합성

내용 파일(무엇을 보여 줄지) + 템플릿(어떤 틀에 담을지) → `<out>.mp4` + `<out>_썸네일.png`.
템플릿은 자주 바뀌므로 `templates/<이름>/` 폴더 하나 = 템플릿 하나로 관리한다. 등록된 템플릿은 고치지 말고, 바뀐 디자인은 새 이름으로 등록한다(예전 편을 다시 뽑을 수 있게).

**역할:** 디자인은 사용자가 정한다. 템플릿 이미지에 없는 요소(애니메이션, 효과음, 전환)는 지어내지 말고 묻는다.

아래에서 `$T` = `.claude/skills/shorts-template`.

## 등록된 템플릿

| 이름 | 모양 | 등록 |
|---|---|---|
| `daechi-navy` | 남색 #161147 바. 위 제목 2줄(노랑/흰, 좁고 굵은 글꼴) · 가운데 영상 1080×912 · 영상 아래쪽 상자 없는 흰 자막 · 아래 손글씨 "‘선착순 마감 강의 소식’은? / ‘대치동캐슬’ 톡방에서" | 2026-10-31, 롱폼 "공부 잘 시키는 부모님 특징" 4편 |

새로 등록하면 이 표에 한 줄 추가한다.

## A. 새 템플릿 등록

1. **이미지 받기.** 가장 좋은 건 1080×1920 원본 디자인 파일. 유튜브 화면 캡처면 테두리·진행 막대 같은 UI가 섞이니 measure.py 가 떼어 낸다. 함께 물을 것:
   - 쓴 글꼴 이름이나 파일(.ttf/.otf) — 있으면 그대로 쓴다
   - 매번 바뀌는 부분(제목·자막)과 고정 부분(안내 문구·로고) 구분
   - 템플릿 이미지에 보이는 사람·글은 예시일 뿐인지
2. **재기.**
   ```bash
   python3 $T/scripts/measure.py <템플릿.png> <scratchpad>/meas
   ```
   - 위·아래 단색 바, 영상 칸(`video.y`, `video.h`), 바 안 글자 줄마다 세로 중심·높이·폭·글자색이 나온다.
   - 영상 위 자막은 배경이 영상이라 자동으로 못 찾는다 → `meas/measure.png` 를 열어 보고 직접 잰다(세로 중심, 글자 높이).
   - 제목 첫 줄과 둘째 줄 색이 다르면 줄마다 `lines[].color`. 일부 낱말만 강조색이면 `title.accent` + 내용 파일에서 `[[ ]]`.
3. **글꼴 맞추기.** 사용자가 글꼴을 주면 그걸 `templates/<이름>/fonts/` 에. 없으면 비슷한 무료 글꼴(Google Fonts, OFL)을 받아 비교한다:
   ```bash
   # 후보 받기 (scratchpad 에)
   curl -sfLO https://raw.githubusercontent.com/google/fonts/main/ofl/blackhansans/BlackHanSans-Regular.ttf
   python3 $T/scripts/fontcmp.py meas/normalized.png <세로중심> <높이> "#글자색" "<그 줄 문구>" cmp.png 후보1.ttf 후보2.ttf
   ```
   - 맨 위 원래 글자와 후보를 같은 높이로 나란히 그려 준다. "폭 비율"이 1보다 크면 `squeeze`(가로 누르기)로, 낱말 사이가 넓으면 `word_gap` 으로 맞춘다.
   - 지금까지 맞춰 본 것: 좁고 굵은 제목 → Black Han Sans + squeeze 0.87 + word_gap 0.2 / 굵은 고딕 자막 → Pretendard-Bold / 펜 손글씨 → Nanum Pen Script. 다른 후보: Do Hyeon(제목), Gaegu·Gamja Flower·Hi Melody(손글씨).
   - 대체 글꼴을 썼으면 사용자에게 "원래 글꼴 파일을 주면 바꾼다"고 알린다.
4. **template.json 쓰기** — `templates/daechi-navy/template.json` 을 복사해 값만 바꾼다(아래 "템플릿 설정"). `reference.png` 로 원본 이미지도 같이 둔다.
5. **확인.** 아무 내용 파일로 `--thumb-only` 를 돌려 썸네일을 만들고, 템플릿 이미지와 같은 자리를 잘라 위아래로 붙여 비교한다(제목·고정 문구·자막 위치와 크기, 글자 굵기). 다른 곳은 고쳐서 다시.

## B. 합성

```bash
python3 $T/scripts/compose.py <템플릿 이름> <내용.json>               # 썸네일 + 영상
python3 $T/scripts/compose.py <템플릿 이름> <내용.json> --thumb-only  # 썸네일만 (제목 폭·장면 확인용)
```

- 내용 파일은 보통 **longform-shorts** 스킬이 만든다. 형식은 아래 "내용 파일".
- `[경고]` 가 나오면(제목·자막 줄이 너무 김, 자막이 0.5초 미만) 문구를 고쳐 다시. 제목은 글자 크기를 줄이지 말고 문구를 다듬는다("팔굽혀펴기를 시작한 이유" → "팔굽혀펴기 시작한 이유").
- 1분 남짓 영상 하나에 약 50초 걸린다(맥미니). 여러 편은 백그라운드로.

### 확인 — 렌더 뒤 반드시

1. **원본에 박힌 글씨가 영상 칸에 비치지 않는지.** 원본 자막 상자뿐 아니라 가끔 나오는 큰 강조 문구도 있다. 영상 칸 아래 가장자리를 1초 간격으로 모아 본다:
   ```bash
   ffmpeg -v error -y -i out.mp4 -vf "fps=1,crop=1080:220:0:<영상 칸 아래 끝-220>,scale=270:55,tile=6x13" -frames:v 1 band.png
   ```
   비치면 내용 파일의 `clean.y1` 을 줄인다(그 편만 줄이면 편마다 확대 정도가 달라지니, 같은 원본의 다른 편도 같은 값으로).
2. **썸네일 표정.** 말하는 영상은 눈 감은 프레임이 잦다. 0.25초 간격으로 후보를 뽑아 눈 뜨고 정면인 시각을 `thumb` 에 쓴다(`-ss` 를 `-i` 앞에 둔 방식으로 뽑아야 compose 와 같은 프레임).
3. **소리 이음새.** 잘라 붙인 결과를 다시 받아써서 낱말이 잘리지 않았는지 본다(`~/.venvs/whisper/bin/python source/clip_words.py out.mp4`). "불평등"이 "성등"으로 나오면 앞 글자가 잘린 것 → 구간 경계를 당긴다. 짧은 조각만 받아쓰면 틀리기 쉬우니 앞뒤를 붙여 다시 확인.
4. 사용자에게는 결과 경로·길이·바뀐 자막만 알리고, "처음부터 끝까지 재생 확인은 아직"이라고 말한다. 확인용 이미지는 scratchpad 에 두고 내밀지 않는다.

## 내용 파일 (내용.json — 경로는 이 파일 기준)

```jsonc
{
  "source": "../../universe-test/원본.mp4",
  "out": "01_서울대엄마_팔굽혀펴기",          // 결과 파일 이름
  "out_dir": "out/universe_shorts",          // 프로젝트 루트 기준, 생략 시 out/shorts
  "title": ["서울대 엄마가", "팔굽혀펴기 시작한 이유"],   // 줄 수 = 템플릿 title.lines 수, [[ ]] = title.accent
  "clean": { "y0": 0, "y1": 846, "cx": 959 },  // 원본에서 박힌 글씨 없는 세로 범위 + 인물 가로 중심
  // 또는 "crop": { "x": 458, "y": 0, "w": 1002, "h": 846 } 로 직접
  "thumb": 840,                               // 썸네일 장면(원본 초)
  "parts": [[825.55, 844.55], [844.70, 854.55]],  // 이어 붙일 원본 구간(초)
  "captions": [ { "from": 825.55, "to": 827.50, "text": "[[서울대]] 학부모였어요" } ]  // 원본 시각, 한 줄
}
```

`clean` 을 주면 템플릿 영상 칸 비율(1080:video.h)로 그 범위 안에서 가장 크게 잘라 쓴다 — 같은 내용 파일을 다른 템플릿에 넣어도 그대로 된다.

## 템플릿 설정 (templates/<이름>/template.json)

| 키 | 뜻 |
|---|---|
| `size` | [1080, 1920] |
| `background` | 바 색(영상 칸 밖 전체) |
| `video` | `{y, h}` 영상 칸. 가로는 화면 전체 |
| `title` | `font`(폴더 기준 경로), `size`, `squeeze`(가로 누르기), `word_gap`(낱말 사이, 글자 크기 배), `stroke`·`stroke_color`(외곽선), `accent`, `lines: [{y, color}]`(줄마다 세로 중심·색) |
| `caption` | `font`, `size`, `y`(세로 중심), `color`, `accent`, `stroke`(검정 외곽선), `shadow_blur`(퍼진 그림자, 0이면 없음) |
| `texts` | 고정 문구 `[{text, font, y, width 또는 size, color, stroke}]` — `width` 를 주면 그 폭에 맞춰 크기를 정함 |
| `images` | 고정 이미지 `[{file, x, y, w}]` (로고 등, 폴더 안 PNG) |

새 디자인 요소(예: 자막 상자, 두 줄 자막, 진행 막대)가 필요하면 compose.py 에 선택 키로 추가하고, 기존 템플릿 결과가 바뀌지 않는지 한 편을 다시 뽑아 비교한다.
